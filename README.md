
# Анализатор зависимостей пакетов

Практическая работа № 2 по конфигурационному управлению.

**Вариант:** 19  
**Язык:** Python  
**Текущий этап:** 3 — основные операции

## Описание

CLI-приложение для анализа зависимостей пакетов
Alpine Linux (apk).

## Реализованная функциональность

- Чтение параметров командной строки.
- Получение APKINDEX из репозитория Alpine Linux.
- Поиск пакета по названию и версии.
- Извлечение прямых зависимостей.
- Построение графа зависимостей.
- Рекурсивный обход DFS.
- Обработка циклических зависимостей.
- Тестовый режим с локальными TXT-файлами.
- Обработка ошибок.
- Автоматические тесты.

## Структура проекта

- `src/main.py` — запуск приложения.
- `src/config.py` — обработка параметров.
- `src/apk_index.py` — работа с APKINDEX.
- `src/graph.py` — построение графа и DFS.
- `src/test_repo.py` — чтение тестового графа.
- `tests/` — автоматические тесты.
- `tests/data/` — тестовые репозитории.
- `run.bat` — запуск в Windows.

## Требования

Python 3.10 или новее.

Дополнительные библиотеки не требуются.

## Параметры командной строки

- `--package` — начальный пакет.
- `--repository` — URL репозитория или путь к TXT.
- `--version` — версия начального пакета.
- `--test-mode` — использование тестового репозитория.
- `--ascii-tree` — зарезервирован для этапа 5.

## Запуск с реальным репозиторием

```powershell
python -m src.main --package curl --repository https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64/ --version 8.14.1-r2
```

## Запуск в тестовом режиме

```powershell
python -m src.main --package A --repository tests/data/sample_repo.txt --version 1.0 --test-mode
```

## Проверка циклических зависимостей

```powershell
python -m src.main --package A --repository tests/data/cycle_repo.txt --version 1.0 --test-mode
```

## Автоматические тесты

```powershell
python -m unittest discover -s tests -v
```

## Особенности

Граф строится рекурсивным алгоритмом DFS.

Для предотвращения бесконечного обхода циклов
используется множество посещённых вершин.

Тестовые пакеты обозначаются большими
латинскими буквами. Формат файла:

```text
A: B C
B: D
C: D
D:
```

## Ограничения

В реальном режиме используется один APKINDEX.
Для начального пакета проверяется точная версия.

Для остальных пакетов не реализован полный
решатель ограничений версий apk.

Виртуальные зависимости, которые нельзя
сопоставить с именем пакета, остаются
конечными вершинами графа.

Графический вывод и ASCII-дерево будут
реализованы на пятом этапе.
